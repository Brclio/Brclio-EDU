# 课程目录视觉复核（2026-11-02）

本轮在同版 Chromium、1280 × 900 视口中，用原站已加载的页面与本地页面截图逐项复核。保留 Brclio 品牌、本地免登录学习入口与学习记录；原站账号、会员、支付及二维码不作为课程视觉一致性目标。

## 完成的范围

- 28 门课程主页均重新访问并截图，包含两种课程版式、所有课程封面及页面实际渲染的章节小图。四张联系表逐张人工查看：`output/catalog-visual-review/all-courses-sheet-{1,2,3,4}.png`。原站收集 292 个 img，本地 202 个；差额主要来自原站商业区域图片。非空 URL 的图片全部加载成功；原站 011 / 013 自身存在空图片槽，单独记录，未算作资源加载成功。
- 21 对真实截图裁片：列表卡片、学习按钮默认和 hover、分类标签默认和 hover；Solo 标签、章标题、展开/收起箭头、课程卡片默认/hover/完成；Article 标签、学习方式、展开/收起章标题、预览课程行默认/hover、预计时间、难度。所有裁片的尺寸一致，RGB 最大通道差超过 8 的像素均为 0。两个分类标签存在不超过 8 的抗锯齿差，未声称逐字节相同。
- 完成态原站裁片通过原站公开组件的真实 done 类、文案、图标构造，报告中明确标注 fixture；不是伪造已登录学习结果。本地完成态通过持久化进度及 storage 事件进入。
- 原有 28 课几何/操作核查与移动端结果见 `docs/course-overviews-full-audit.md`。本轮新增截图细节检查，不能将旧几何结果当作本轮整站像素证明。

## 修复

- 列表难度文字灰色、学习按钮的白底/字体/hover 蓝色与边框、卡片阴影过渡和逐项入场动画；移除原站不存在的分类文字 hover 变色。
- Solo 使用源 PNG 章节箭头，收起时不凭空旋转；修正完成态绿色、章节进度颜色和边框、卡片上沿与状态文字基线；移除源站不存在的额外 hover 阴影。
- Article 使用原 SVG 路径和正确大小的时钟、展开箭头、学习方式、预计时间、难度及完成图标；统计标签蓝色和圆角、课程行图标间距及垂直位置；移除源站不存在的课程行 hover 底色。
- SVG sprite 只由 symbol 提供 viewBox，避免外层再次设置 viewBox 导致图形变形。章节标题使用单个文本节点；原有多个 JSX 文本节点造成中英文交界处的 0.015625px 排版差和 262 个字形像素差，修改后裁片归零。

## 可复跑证据

运行 `node tests/catalog-visual-review.mjs --all-courses` 和 `node tests/catalog-visual-states.mjs`。测试脚本保留原站会话名称，依赖原站页面可访问及资产已加载；新的源会话当时存在 CDN 资源失败，故本轮复用已加载成功的原站会话并再次核验 naturalWidth。

- 图库：`output/catalog-visual-review/index.html`
- 28 课资源及截图清单：`output/catalog-visual-review/all-courses.json`
- 21 对样式、SVG、矩形、截图与像素结果：`output/catalog-visual-review/states.json`

截图先获取完整视口，再按实际可见位置裁片，避免浏览器 CLI 在滚动后 selector screenshot 偏移。截图不修改页面样式。联系表便于检查全课程封面和图标；状态裁片便于检查字体、边框、颜色和实际 hover。

尚未以本轮脚本覆盖每门课所有章节的每个 hover、每条课程的已完成状态、所有浏览器和设备；不可据此声称全站所有状态逐像素一致。阅读器侧栏本轮只协助校正共享图标和章节文本节点，独立完整截图复核仍由阅读器专项结果覆盖。
