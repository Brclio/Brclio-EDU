- 003 首页此前遗漏“课程目标”与 8 项目标，已恢复原始顺序和双列/手机单列排版。
- 001、006 的 `__default` 分类原站直接平铺课节，本地此前多出章节标题及目录内边距；已恢复平铺与每行 12px 上下间距。

## 本轮测量

同一 Chromium、相同视口，实时读取原站和本地 DOM。先等待课程标题切换、图片结束加载与入场动画结束，再比较每个匹配元素的 x、y、width、height。分步课程原站会延时滚动到课节，报告使用文档坐标抵消滚动偏移，未把浏览器滚动位置误报为布局差异。

| 范围 | 对照组数 | 失败组数 | 最大矩形坐标差 |
| --- | ---: | ---: | ---: |
| 1280×900：课程列表与全部 28 个课程首页 | 250 | 0 | 0 CSS px |
| 390×844：课程列表与 015、011、002、003、001、006 首页 | 62 | 0 | 0 CSS px |

桌面共比较 1,295 个元素，手机共比较 400 个元素；每组包含全部匹配元素，而不只第一行。包括卡片、统计标签、概要、课程目标后的各级标题、全部初始展开章节和课节行。001、006 的章节头为双方均不存在的预期状态，其他组若无元素则失败。手机 003 的源站与本地截图另经人工查看，标题、统计、概要正文、目标列表对齐。

真实操作另外比较了 8 个分类的全部课程数量和顺序，以及展开第二章、切回第一章、再次折叠第一章。源站与本地共 22 条检查全部通过；三次目录操作的可见卡片数分别为 8、11、0。

## 结论边界

这里证明的是上述视口、初始课程首页状态的指定矩形布局；不等于所有课程正文、所有滚动位置、全部编辑器状态的逐像素认证。课程正文和挑战交互另由对应回归报告覆盖。品牌、公开学习入口与未接入的原站账号/销售服务是明确保留的产品区别。课程目录的学习状态取自本地学习记录，不能把原站匿名访问的会员锁定视觉当成同一学习状态比较。

## 阅读器断点交叉复核

独立复核阅读器改动时发现 415–700px 的侧栏初始状态及 415–1259px 的正文宽度与原站不同，已由阅读器实现修复。`tests/article-reader-breakpoint-audit.mjs` 使用 001/1，在 390、414、415、640、700、768、1280 七个视口重新载入两站，等待正确标题、样式表、CodeMirror 以及至少 600ms 连续稳定几何。

42/42 项通过：侧栏显示状态、侧栏矩形、阅读区域矩形、正文内容框、标题矩形、文档总宽均一致。414px 及以下隐藏侧栏；415px 起侧栏 300px、正文 960px，因此窄桌面/平板视口保持 1260px 文档宽度。手机源站将 16px 内边距放在正文容器，本地放在外层阅读区域，测试比较实际内容框，避免将不同包裹层的外框误认成视觉差异。

```sh
node tests/article-reader-breakpoint-audit.mjs
```

结果在 `tests/article-reader-breakpoint-audit.json`。该检查针对阅读器外框与标题，不把正文加载稳定等同于课程内所有编辑器行为验证。
