## 仍然明确保留的边界

- 原站失效的箭头与 `hello_html` 仍有明确标记的重建资源；部分第三方教学响应是有来源的兼容副本，并非失效历史页面原件。全部动态爬取地址、私人账号操作不能由固定响应镜像覆盖。见 [内容来源与本地化](content-localization-current.md)。
- 原站私有隐藏判题与 AI 服务没有复制为本地服务；公开答案/公开用例按实际结果判定，不伪造隐藏通过。两题组第 179 题先前被误判为不可达；后来实际验证发现它可经键盘 Tab 进入，本地已恢复，旧报告附有更正。公开组件自身报错及受限导图在专项中单独记录，不算原实页已验证。
- Python、JavaScript、SQL 和编辑器资源同源运行；原生编译及 Python 多进程有自部署隔离运行器。本机尚无 Docker 环境，真实 C/C++/Java/Go/Swift 测试使用既有 Brclio 自有隔离服务，未调用原站运行服务，也不能写成此 Mac 已全离线运行。见 [本机运行条件](local-runtime-readiness.md)。
- 以上覆盖全量公开内容与所列组件状态，不能据此宣称所有设备、所有快捷键、任意编辑程序和全部后端行为都与原站完全一致。品牌及开放学习按用户已确认的要求保留。

最终 `npm test` 102/102 通过，TypeScript/Vite 生产构建及 `git diff --check` 通过。构建保留大型代码包提示；本轮没有执行线上部署。
