## 本轮修复的核查漏洞

`import-verify.py` 现在校验预期课节数、挑战总数、不同引用资源数与已解决引用数，检查课程/课节重复，支持嵌套本地资源目录及引用别名。源导入 manifest 仍有失败、或内容文件超过部署 25 MiB 上限时，验收必须失败；此前这些情况可能仅显示在报告中而不影响 `verified`。

实时源比较原先只展开标量，可能忽略新增 `null`、空对象变成空数组或 `true` 与 `1` 的差异。现在使用精确 JSON 结构比较，并要求每个源端点规范化 SHA-256 相同。
