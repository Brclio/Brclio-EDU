# 课程列表与首页样式对照

2026-11-02 使用 agent-browser 在同一 Chromium、1280 × 900 视口实际打开原站与本地应用，读取布局坐标并截图。原站文章课程首页使用真实 `/course/002/overview`，没有用 `/learn` 路由替代。

对应实现为 `src/CourseCatalog.tsx`、`src/CourseOverview.tsx`、`src/ArticleOverview.tsx`，样式隔离在 `src/course-catalog.css` 和 `src/course-overview.css`。未覆盖阅读器全局 CSS。

实际操作额外确认：390px 视口点击“前端课程”后只显示 JavaScript 一课；切回全部后可进入 015 首页，折叠第一章移除 11 张展开卡，重新展开后可进入 `#/course/015/page/936`。这几步页面宽度均未超出 390px。全部课程路由与练习流程由独立 `tests/app-solo-audit.mjs` 验证，本次仅更新其导航选择器。

## 可复跑材料

```sh
npm run dev
node tests/course-layout-audit.mjs
# 也可通过 AUDIT_BASE 指向部署地址
```

- 脚本：`tests/course-layout-audit.mjs`
- 逐元素原站 / 本地坐标、字体与结果：`tests/course-layout-audit.json`
- 同视口截图：`output/course-layout-audit/catalog-{source,local}.png`、`solo-015-{source,local}.png`、`article-002-{source,local}.png`、`article-002-toc-{source,local}.png`

脚本依赖原站当前公开 DOM 类名；原站改版后应重新取证，不能把选择器失效当作一致。原站会员欢迎弹层会通过真实点击关闭，再返回课程目录。

## 保留的产品差异与范围

按公开学习要求保留 Brclio 品牌、本地课程 / 编程 / 学习记录导航；登录、付费、扫码购买、会员锁定和原站销售服务不保留。所有课节与挑战可以直接进入，时钟 / 完成图标替代原站锁定状态。原站其他商业产品入口及其学员服务评价没有冒充为本部署的功能或评价。

手机布局避免沿用原站 1330px 的桌面最小宽度。这份报告验证课程列表与两个代表首页的布局几何、文本排版和实际操作；并不声称所有课程、所有分辨率的每个像素完全相同。图标绘制和上述公开学习入口仍有明确差异。
